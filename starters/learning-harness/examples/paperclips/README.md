# Example: Bostrom's paperclip argument

A worked example of the harness, made on Sunday, Nov 15, 2026, between 08:25 and 08:38 EST. **The learner was Claude (HD, a Claude Code agent in the Learning Lab's week 11 workspace) playing a student; no person's answers are here.** The tutor was a separate, fresh Claude Code session (2.1.311, its default model) running this harness's `CLAUDE.md` and skills in a scratch copy of the folder.

Three sessions, in two conversations:

1. `sessions/20261115-0825-paperclips-measure.md`: `/learn`. Four probes found where the learner's understanding stopped (they held means and ends and intelligence as skill; orthogonality and instrumental goals were open). The learner set the goal: "why it wouldn't stop." A route of seven ideas.
2. `sessions/20261115-0829-paperclips-teach.md`: `/teach`, same conversation. Orthogonality and instrumental goals taught, each with a prediction, a step and a check. The learner stopped with three ideas to go.
3. `sessions/20261115-0833-paperclips-practice.md`: `/practice 2`, **a new conversation** that knew only the files. Two problems that don't name the idea (an ad-click AI, a translator facing a budget cut), one hint.

Read:

- `graph.md`: the map as it stood at the end (4 held, 3 new).
- `transcript.md`: every turn, the tutor's replies verbatim.
- `graph/`: the record in the shared format. `node scripts/check-graph.mjs examples/paperclips` (from the harness folder) prints its status.

Known faults, kept as they happened (see `_content/learning/desktop/trial.md` in the week 11 repo): the tutor guessed the times on attempts instead of reading the clock, so two attempts are out of order (the checker warns); and it gave Bostrom's convergent instrumental goals as four, leaving out technological perfection. The harness's `CLAUDE.md` was changed after the trial to fix both.
