# Tech tree and unlocks

## Definition

New options open in a set order, each unlocking the next, so progress means choosing a path through a tree of prerequisites.

On GM's card: "Progress opens new options in a set order." [1]

## Description

In games:

- **[Civilization](../games/civilization.md)**: Researching one technology opens the ones that depend on it, from pottery, the wheel and the alphabet onward. [2]
- **[Universal Paperclips](../games/universal-paperclips.md)**: New options and phases open up as the player invests resources such as money, raw materials and computer cycles. [3]

**Shows it** (GM's card): *Civilization* [1]

**With AI** (HI): Whatever the goal, the tree leads to the same nodes: instrumental convergence as a tech tree. [1]

**In our game** (Nov 14 rulesets): no (proposed: a convergence tech tree) [1]

## How to

**Try it in two minutes** (GM's card): Draw a tree of five inventions on paper; you can only build one when the one below it is done. [1]

**Build it** (GM's card): A JSON tree Claude drafts from a theme, shown as a map players unlock on `/stage`. [1]
