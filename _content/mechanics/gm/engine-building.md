# Engine building

## Definition

Early choices produce resources or abilities that make later turns stronger, so the player builds a machine that pays more each round.

On GM's card: "Early purchases make later turns stronger." [1]

## Description

In games:

- **[Splendor](../games/splendor.md)**: Gem cards bought early give a permanent discount on later cards, so each purchase makes the next one cheaper. [2]
- **[Cookie Clicker](../games/cookie-clicker.md)**: Each building bought raises the cookies made per second, which buys more buildings. [3]

**Shows it** (GM's card): *Splendor* [1]

**With AI** (HI): The AI's engine is the one that wins: each data center makes the next cheaper (or, in Thorstad's setting, dearer). [1]

**In our game** (Nov 14 rulesets): partly: the AI's growth compounds; the humans' engines are proposed [1]

## How to

**Try it in two minutes** (GM's card): Each card you buy makes the next one cheaper. Buy in an order that snowballs. [1]

**Build it** (GM's card): Claude Code builds a card market where each card bought lowers the price of the next. [1]
