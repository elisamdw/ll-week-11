# Core loop

## Definition

The short cycle of actions a player repeats throughout a game, around which the rest of the game is built. Each pass through the loop changes the state a little and sets up the next pass.

On GM's card: "The short cycle of actions the player repeats all game." [1]

## Description

In games:

- **[Universal Paperclips](../games/universal-paperclips.md)**: Make clips, sell them, buy wire and clip-making machines with the money, make more clips; later stages keep the loop and change what it is made of. [2]
- **[Tetris](../games/tetris.md)**: A piece falls, the player turns and places it, full lines clear, and the next piece falls. [3]
- **[League of Legends](../games/league-of-legends.md)**: Kill minions for gold, go back to base to buy items, return to fight stronger; the ENGL 189VG brainstorm names it as an example of a loop. [4]
- **[Data Center](../games/data-center.md)**: Each round the AI draws a card, upkeep runs, then each faction acts; ten rounds of the same cycle. [5][6]

**Shows it** (GM's card): *Universal Paperclips* (make, sell, invest) [1]

**With AI** (HI): The AI's loop runs on its own beside the players' loop; the drama is where the two meet. [1]

**In our game** (Nov 14 rulesets): yes: every version (AI draws, upkeep, factions act) [1]

## How to

**Try it in two minutes** (GM's card): Name the three things you do over and over in a game you know. Swap one and say what changes. [1]

**Build it** (GM's card): Ask Claude Code for a one-page loop with three buttons on `/launch`; play it for two minutes, then change one step. [1]

## Why to

The ENGL 189VG team's brainstorm asks "what would be a loop that's not combat?" [4]

**Proposed, for Marlon to choose:**

1. Have students name the core loop of a game they know in one line, then name the loop of a course (read, discuss, write, get feedback) and compare.
2. Use the loop as the unit of a game design exercise: build the smallest loop that is fun to repeat three times before adding anything else.

## Home game version

### In a regular classroom

**Proposed, for Marlon to choose:**

1. Draw the loop as a circle of three or four verbs on 11x17 paper and play it with tokens for five passes.
2. Run a round of the week's game on paper, with one person reading out each phase of the loop.

### Digitally

**Proposed, for Marlon to choose:**

1. Play Universal Paperclips for ten minutes and write down the loop each time it changes.
2. Ask Claude to build a single-page game whose only content is one loop, then add one thing to it.
