# Score and points

## Definition

A running number that turns what players do into one measure, so progress can be compared between players, or between one attempt and the next.

On GM's card: "A number that turns actions into progress you can compare." [1]

## Description

In games:

- **[Pac-Man](../games/pac-man.md)**: Dots, power pellets, ghosts and fruit each add points, and eating ghosts in a row makes each one worth more. [2]
- **[Scrabble](../games/scrabble.md)**: Each letter has a point value and premium squares multiply it, so where a word goes can matter more than which word it is. [3]
- **[Data Center](../games/data-center.md)**: Public trust and present harms are tracks, and each faction's private goal is a threshold on one number (Energy, harms, Money or trust). [4]

**Shows it** (GM's card): *Pac-Man* [1]

**With AI** (HI): Scoring is where an AI's goal is written down; whatever the score rewards, an optimizer will pursue to the letter (perverse instantiation). [1]

**In our game** (Nov 14 rulesets): yes: Data Center and Normal Technology (trust and harm tracks, each faction's own score) [1]

## How to

**Try it in two minutes** (GM's card): Score a conversation: a point for every question asked. Watch how people start talking. [1]

**Build it** (GM's card): A score counter on `/stage` that every cue adds to. [1]

## Why to

**Proposed, for Marlon to choose:**

1. Pair it with Nguyen's "value capture": what happens when a number stands in for what you care about (a grade, a citation count)?
2. Ask students to score a game two ways and see how the scoring changes the play.

## Home game version

### In a regular classroom

**Proposed, for Marlon to choose:**

1. A tally on the whiteboard, with the rule for points written beside it so the class can argue with it.
2. Give each group a different scoring rule for the same task and compare what they did.

### Digitally

**Proposed, for Marlon to choose:**

1. A shared spreadsheet or form whose total updates live on the projector.
2. A small web page that shows one score and the rule that produces it, editable by the class.
