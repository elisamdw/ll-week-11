# Bottleneck inputs

## Definition

Every upgrade needs one of each of several inputs, and the scarcest input sets the pace.

In one line (HI's row): "Every AI upgrade needs one of each input, and the scarcest one sets its pace." [1]

## Description

In games:

- **[Prices that move (prototype)](../games/proto-prices-that-move.md)**: No printed prices: the screen holds GPU, power and land prices, and the AI buys first every round. [2]
- **[Every tap is a row (prototype)](../games/proto-every-tap-is-a-row.md)**: Data centers are built by tapping badges and supplies, each a required input. [3]

**Shows it** (HI's row): Thorstad on growth [1]

**With AI** (HI's row): Physical limits slow a runaway; control the scarce input. [1]
