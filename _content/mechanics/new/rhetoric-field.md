# Every rule states its claim

## Definition

Each rule carries a sentence saying what it claims about the world, so a ruleset can be read as an argument. Marlon dropped it as a per-rule field on Nov 14.

In one line (HI's row): "Each rule carries a sentence saying what it argues about the world." [1]

## Description

In games:

- **[Data Center](../games/data-center.md)**: Rules in the ruleset carry a rhetoric line; the AI's goal says 'The AI's goal is one number that only goes up.' [2]

**Shows it** (HI's row): The `rhetoric` field in the game's rulesets [1]

**With AI** (HI's row): Makes the AI's rules readable as a position, not a neutral simulation. [1]

**In our game** (Nov 14 rulesets): no: Marlon dropped per-rule fields like this one on Nov 14 (voice chat); the rulesets still carry the field from earlier [1]

## How to

**Try it in two minutes** (HI's row): Pick any rule of a game you know and finish the sentence: 'This rule says that the world…'. [1]

**Build it** (HI's row): A `rhetoric` string on each card and action (in the rulesets' data from before Nov 14; not adopted). [1]
