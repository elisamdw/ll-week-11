# Benefit tracks

## Definition

Each AI site also advances a public good (health, mind, development, peace, meaning), so the game counts what AI gives as well as what it takes. [2]

In one line (HI's row): "Each AI node also advances a good: health, mind, development, peace, or meaning." [1]

## Description

In games:

- **[Normal Technology](../games/normal-technology.md)**: Every site the AI holds pays something back to the region. [3]
