# Threshold gesture

## Definition

A movement counts as an action only when it crosses a set threshold of speed, angle or force, and the threshold decides what the move takes. It is one kind of gesture input: the swing, not the shape.

In one line (EG's row): "A movement fires an action only when it crosses a set speed, angle or force." [1]

## Description

In games:

- **[Wii Sports](../games/wii-sports.md)**: Swinging the Wii Remote hits the ball in tennis, and the speed of the swing changes the shot. [2]

**Shows it** (EG's row): Wii Sports (the swing's speed and timing set the shot) [1]

**With AI** (EG's row): Where the threshold sits decides who can play: a tuning question about bodies. [1]

**In our game** (Nov 14 rulesets): no [1]

## How to

**Try it in two minutes** (EG's row): Clap to act, but only claps loud enough to hear across the room count. [1]

**Build it** (EG's row): Measure a landmark's speed or a joint's angle each frame and fire when it crosses a threshold; the threshold is a number to tune. [1]
