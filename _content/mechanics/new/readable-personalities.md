# Readable personalities

## Definition

A few one-line rules for an AI, each named and colored, so players read them as characters.

In one line (HI's row): "Three or four one-line AI rules, each named and colored, read as characters." [1]

## Description

In games:

- **[Pac-Man](../games/pac-man.md)**: Each of the four ghosts chases Pac-Man by its own rule, and players learn to read them as personalities. [2]
- **[The phone plays the AI (prototype)](../games/proto-the-phone-plays-the-ai.md)**: The AI spreads by a rule the players can read. [3]

**Shows it** (HI's row): *Pac-Man*'s four ghosts (1980) [1]

**With AI** (HI's row): Players read character into simple, visible rules. [1]

**In our game** (Nov 14 rulesets): partly: the AI deck is readable; named sub-agents are proposed [1]

## How to

**Try it in two minutes** (HI's row): Give each AI piece a one-line rule ('go for the cheapest power'); let players name them. [1]

**Build it** (HI's row): Named AI sub-agents, each with one targeting rule for `spread`. [1]
