# Any-map test

## Definition

The AI's rules must work on a map they were not written for, a test of whether its play is general. [2]

In one line (HI's row): "The AI's rules must work on a map they were not written for." [1]

## Description

In games:

- **[Civilization](../games/civilization.md)**: Each game can start on a newly generated map, so the computer players must play maps no one designed for them. [3]
