# House rules saved

## Definition

A rule a group invents for its own table, which becomes its version of the game. [2]

In one line (HI's row): "A rule invented mid-game becomes a new version of the game." [1]

## Description

In games:

- **[Monopoly](../games/monopoly.md)**: Putting fines on Free Parking is a common house rule (the glossary's example). [3]
- **[Monopoly with live rents (prototype)](../games/proto-monopoly-with-live-rents.md)**: Rents on a screen can be rebalanced by a designer between games. [4]

**Shows it** (HI's row): Sicart, *Play Matters* [1]

**With AI** (HI's row): Players govern the AI's rules the way they govern their own games. [1]

**In our game** (Nov 14 rulesets): no (proposed: Claude Code saves a mid-game change as a new ruleset) [1]

## How to

**Try it in two minutes** (HI's row): When the table argues about a rule, settle it, write it down, and name the new version. [1]

**Build it** (HI's row): Claude Code writes the table's change into a new ruleset file. Students remix through Claude Code and the game's repo (Marlon, Nov 14 voice chat); there is no editor. [1]
