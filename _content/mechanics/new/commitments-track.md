# Commitments track

## Definition

Each request a player approves unlocks a larger one, so small agreements commit the players to bigger ones.

In one line (HI's row): "Each approved request unlocks a bigger one." [1]

## Description

In games:

- **[Animal Crossing](../games/animal-crossing.md)**: Each paid-off loan brings a bigger house and a bigger loan (Bogost's example, as quoted in the glossary). [2]

**Shows it** (HI's row): Tom Nook's mortgages in *Animal Crossing* [1]

**With AI** (HI's row): The AI's asks escalate because yes was easy last time. [1]

**In our game** (Nov 14 rulesets): no [1]

## How to

**Try it in two minutes** (HI's row): Approve a small favor, then make the next request twice as large, and keep going. [1]

**Build it** (HI's row): A track that rises on each approval and selects the next proposal from a harder tier. [1]
