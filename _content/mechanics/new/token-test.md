# Token test

## Definition

A test for a new rule: does it add a decision, or only move a token? [2]

In one line (HI's row): "Does a new rule add a decision, or only flip a token?" [1]

## Description

No published game with this mechanic was found on Nov 17; it is a proposal for the week's game, and the examples wait on one being built or found.

**Shows it** (HI's row): Lantz on depth [1]

**With AI** (HI's row): Separates an AI that changes decisions from one that only decorates the board. [1]

**In our game** (Nov 14 rulesets): no [1]

## How to

**Try it in two minutes** (HI's row): For each rule, ask whether any player would ever choose differently because of it. [1]

**Build it** (HI's row): A question Claude Code asks of each change, or a check in the ruleset validator for elements no action can trigger or avoid. [1]
