# Nested loops

## Definition

Short loops run inside longer ones: a move inside a turn, a turn inside a round, a round inside a game. Nested deeply and run fast, separate turns can look like one continuous agent. [2]

In one line (EG's row): "Short loops run inside longer ones (a move in a turn in a round in a game)." [1]

## Description

In games:

- **[Civilization](../games/civilization.md)**: Each unit moves within a player's turn, and the turns carry a civilization from before 1 A.D. toward the modern era. [3]
- **[Universal Paperclips](../games/universal-paperclips.md)**: Clicks and purchases sit inside projects, and projects inside three stages (the business, Earth, space), each with its own loop. [4]
- **[Data Center](../games/data-center.md)**: A faction's action sits inside its turn, turns inside a round (AI card, upkeep, factions), rounds inside the game. [5]

**Shows it** (EG's row): Civilization (unit moves, turns, eras); Universal Paperclips (clicks, upgrades, stages) [1]

**With AI** (EG's row): Turn-based loops nested fast enough look like an agent that is always on. [1]

**In our game** (Nov 14 rulesets): yes: action, faction turn, round, game [1]

## How to

**Try it in two minutes** (EG's row): Write the week's game as three nested circles: a faction's action, a round, the game. [1]

**Build it** (EG's row): An engine with a step function per level: act, then end the turn, then end the round, then check the end. [1]

## Why to

Marlon, Nov 15 (voice agent's record, as on the card): "with enough enveloping, nested, recursive turn-based things, we could produce the illusion that the agent you're talking to, or the game you're playing, is more human-like or more always-on." [2]
