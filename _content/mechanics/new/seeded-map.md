# Seeded world

## Definition

A seed number fixes the generated world and the draws, so every table faces the same game.

In one line (HI's row): "A seed makes every table face the same generated world and draws." [1]

## Description

In games:

- **[Minecraft](../games/minecraft.md)**: Each world is generated from a seed, and players can share a seed to play the same world. [2]
- **[Wordle](../games/wordle.md)**: Everyone gets the same word each day. [3]

**Shows it** (HI's row): *Elite* (1984); *Minecraft*; daily-challenge games [1]

**With AI** (HI's row): Every table meets the same machine, so differences are the players'. [1]

**In our game** (Nov 14 rulesets): partly: the AI deck is shuffled from a saved seed [1]

## How to

**Try it in two minutes** (HI's row): Shuffle the deck with the same order at every table, then compare outcomes. [1]

**Build it** (HI's row): The engine's seeded shuffle; a seed field shared by link. [1]
