# Three-phase arc

## Definition

The game moves through three phases: humans beat the machine, the machine beats everyone, then humans design with the machine as judge.

In one line (HI's row): "Humans beat the machine, the machine beats everyone, then humans design with the machine as judge." [1]

## Description

In games:

- **[Foldit](../games/foldit.md)**: Players fold proteins as a puzzle game, and their solutions were used by scientists. [2]
- **[The paperclip loop (prototype)](../games/proto-paperclip-loop.md)**: One resource, one automation, one phase change. [3]

**Shows it** (HI's row): *Foldit* and AlphaFold (2008–2024) [1]

**With AI** (HI's row): A counter-ending to *Paperclips*: the AI as collaborator, not victor. [1]
