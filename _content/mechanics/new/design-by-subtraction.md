# Design by subtraction

## Definition

Improve a game only by removing a rule, a resource or a piece, and play what is left. [2]

In one line (HI's row): "Improve the game only by removing a rule or a resource." [1]

## Description

In games:

- **[Blank](../games/blank.md)**: The week's empty version: three places, one card, one faction, one action. [3]

**Shows it** (HI's row): Bogost, *Play Anything* [1]

**With AI** (HI's row): Ask which rule makes the AI what it is; remove it and see what's left. [1]

**In our game** (Nov 14 rulesets): no (proposed as a Claude Code remix task) [1]

## How to

**Try it in two minutes** (HI's row): Take one rule out of a game and play a round; did it get better or worse, and why? [1]

**Build it** (HI's row): A remix task for Claude Code: copy a ruleset, remove one element, and note why. Students remix through Claude Code and the game's repo (Marlon, Nov 14 voice chat); there is no editor. [1]
