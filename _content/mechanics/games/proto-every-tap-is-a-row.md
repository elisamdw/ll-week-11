# Every tap is a row (prototype)

## Definition

Ninety seconds of tapping badges and supplies to build data centers. Every tap writes a row; the board is only those rows replayed. At the end, read the table instead of the board. [1]

## Description

**Made by:** The LL (PB, Claude Code), Nov 15 · **Year:** 2026 · **Form:** LL-made

Mechanics it shows in this inventory:

- **[Rewind and do-over](../gm/rewind-and-do-over.md)**: The board is only the rows of taps replayed, so it can be replayed to any earlier moment. [1]
- **[Bottleneck inputs](../new/bottleneck.md)**: Data centers are built by tapping badges and supplies, each a required input. [1]
- **[The tap as the move](../new/the-tap.md)**: Ninety seconds of tapping badges and supplies to build data centers: every tap writes a row, and the board is only those rows replayed. [1]
