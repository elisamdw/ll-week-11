# Normal Technology

## Definition

The Data Center map rewritten after Narayanan and Kapoor's 'AI as Normal Technology': the AI spreads only where someone approves or signs a deal, every site pays something back, and there is no turn. [1]

## Description

**Made by:** The LL (GL, Claude Code), for week 11 · **Year:** 2026 · **Form:** LL-made

Mechanics it shows in this inventory:

- **[The not-modeled list](../new/not-modeled.md)**: The same six, plus 'A path from here to the turn: this version says there isn't one', so the list states the version's claim. [1]
- **[Benefit tracks](../new/benefit-tracks.md)**: Every site the AI holds pays something back to the region. [1]
- **[Adoption only](../new/adoption-only.md)**: Every new site is a proposal someone approves or a deal someone signs, each site the AI holds pays one Money back, and there is no turn. [1]
