# The concept map, node graph or knowledge graph

## Definition

A diagram of ideas as nodes joined by links (lines, arrows, labeled relations), made by hand with cards, paper and string or on a screen, so that a body of material, an argument or a system can be seen whole and rearranged.

## Description

Marlon, Nov 17, 07:13 (voice agent's record), in his list of LL mechanics: "concept map, or node graph, knowledge graph — those are all interesting", with "ways to achieve these physically, in regular classes, and then in digital ways" [1]. The three names cover a range: a concept map is drawn to show how ideas relate; a node graph is the same picture used to describe a process (each node does something, each link passes something on); a knowledge graph stores the nodes and typed links as data a program can query [8].

Where the LL has done it, from the record:

- **Visual argument-mapping.** The LL's overview: "help an Expository Writing course use visual argument-mapping as a way to understand core moves in academic writing" (undated) [2].
- **Conceptual diagrams of borders.** SOC-STD 98MR, spring 2025: students "used art supplies to create conceptual diagrams and speculative data visualizations" [2].
- **A database of the course in index cards.** SOC-STD 98to (William Stafford), Sept 28, 2026: "Database construction with index cards", where groups went from the course "qua course" to "a database of infrastructural elements" [3]. (A schema, the database's cousin of a concept map.)
- **The agent as a node graph.** Week 9 (ending Nov 6, 2026), Marlon on prompt chaining: "All of that can be understood as a node graph, or metaphorized as a system of human-like roles. 'The question is just which helps you get the best quality work done.'" [4]. He told the LLUFs that "each builds themselves a bot, or more than a bot: a node graph like that, with triggers and, if they wish, loops or heartbeats" [5].
- **The week's ideas as a graph.** Since Nov 13, 2026, this repo shows Marlon's idea cards as a node graph at `/ideas/graph` and the deck at `/cards` views, with saved arrangements [6]; Marlon on Nov 15: "I want to be able to view in multiple ways, as node graph, in manipulable form" [7].
- **A dialogue tree in colored cards.** ENGL 189VG, Oct 26, 2026: "You'll design a short dialogue tree using colored cards" [9], a node graph of a conversation.

A paper concept map as the whole activity of a named session was not found in what I read.

## How to

On a table, as we suggest from the sessions above (no record gives step-by-step instructions):

1. **One node per card or sticky note,** written large enough for the overhead camera or a photo.
2. **Lay out, then link.** Place the nodes on an 11×17 sheet or a whiteboard and draw the links in marker, labeling each with the relation ("causes", "is part of", "answers").
3. **Name the type of graph first.** A dialogue tree branches from one start [9]; an agent's node graph runs from a trigger [5]; a concept map has no start. Telling the group which they are making saves the first ten minutes.
4. **Capture it** from above (see [The overhead view](overhead-view.md)) or on the story board.

On a screen: this repo's `/ideas/graph` (built with `@xyflow/react`) moves nodes and saves arrangements to `_content/ideas/_layouts/` [6]; the week's research compares how Luhmann's slip box, Obsidian, Roam and Logseq, property graphs and RDF, and Tana store nodes and links [8].

What goes wrong, from the record: graphs grow past what a group can hold. Week 9: "We keep hitting this scale of ever more complex graphs: each agent is itself a complex loop-and-graph structure, and then there's the graph of all of those agents" [5].

## Why to

From the record:

- **To understand the core moves of academic writing** (the Expository Writing argument-mapping) [2].
- **To think about course material as a structure, not a sequence:** the Stafford index cards, after Manovich's "databases versus narratives" [3].
- **To choose between two ways of seeing a system:** "a node graph, or ... a system of human-like roles. The question is just which helps you get the best quality work done" (Marlon, week 9) [4].

**Proposed, for Marlon to choose:** what the concept map is for in this week's rooms.

1. TDM 155AI: map a game as a node graph of state and moves before building it.
2. Stafford: the database of infrastructure from Sept 28 drawn as a graph, which becomes the game's board.
3. Presenting: a speaker builds the map live under the overhead camera while talking, so the structure of the talk appears as it is told.

## Home game version

### In a regular classroom

Index cards or sticky notes, a large sheet or the board, and a marker are enough; a phone photo keeps the result. (We suggest this; it is the common classroom form and needs nothing the LL has.)

### Digitally

**Proposed, for Marlon to choose:**

1. This repo's graph view, run by the instructor on the room's screen, with students' cards loaded from Markdown [6].
2. A note tool that draws links as a graph (Obsidian's links and Canvas are among the models in the week's research [8]); each student keeps their own vault.
3. A shared online whiteboard with connectors, for a group map made at once.
