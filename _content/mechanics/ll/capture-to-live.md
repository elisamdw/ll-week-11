# Capture to the live wall

## Definition

A capture station (a camera or phone with a web page) sends each still to a live gallery on a screen and to a channel, where a model adds a short description, so the session's work appears on the wall as it is made.

## Description

TDM 155AI class 3, Sept 23, 2026: "The `/capture` page posted about a hundred stills to Slack during class, each with an AI description written in that station's vocabulary ('key light around the 2 o'clock position, low and fairly close'), so the wall reads like the glossary in use. The AI doesn't make the media; it documents the physical practice and gives it words" [1].
