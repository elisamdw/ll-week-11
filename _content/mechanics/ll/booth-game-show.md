# The game show from the booth

## Definition

A session run as a mock game show: the speaker or contestant performs on the studio floor while an operator in the control booth fires the show's cues (countdown, buzzer, music, title cards) onto the studio screen.

## Description

Marlon, Nov 16, 13:23 (typed): Terry Gipson's EXPOS 40 session on public speaking is "ostensibly one of our most difficult-to-replicate-outside-of-the-studio activities ... In the session students engage in a mock game show activity, so we are creating a 'Home Game' version of it for him" [1]. The show is *Are You Serious?!*: a speaker has to stay serious while a buzzer and a countdown try to crack them [3]. The app (`ll-26-27/expos40`, built Nov 9) is "A keyboard sound board and a 1920×1080 stage for one operator to run Terry's game show 'Are You Serious?!' from the booth": key 1 the countdown, 2 the intro and hovering title, B the "Smile buzzer" [2]. The sessions this term were canceled; the home game is this week's build [3].

## How to

From the app's README: run the board and the stage; the switcher takes the stage window full frame; the operator plays cues from the keyboard [2]. The rules are "written down nowhere the LL has found" [3].

## Why to

From the record: public speaking under playful pressure, in Terry Gipson's course [1][3].

**Proposed, for Marlon to choose:** what the game-show frame does for teaching beyond EXPOS 40.

1. Pressure without consequences: rehearsal for talks and oral exams. Marlon on play, Nov 16, about 17:17 (voice agent's record): "If people don't take the game seriously, it doesn't even work. People have to pretend to be invested, but you also don't want real harm to happen" [1].
2. A role for every student: contestant, host, operator, audience.

## Home game version

### In a regular classroom

The home game: the board on a classroom laptop and projector, run by the instructor or a student; the accessibility research asks that "every action on a key, a visual for every meaningful sound, a timer the host can change or turn off" [3][4].

### Digitally

The same board screen-shared in a call. (Our suggestion.)
