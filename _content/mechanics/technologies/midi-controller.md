# The MIDI controller

## Definition

A keyboard, pad bank or control surface that sends MIDI messages (notes, pad hits, knob values) to a computer, where software maps them to sounds, cues or parameters.

## Description

TDM 155AI, Nov 11, 2026: the class app had "MIDI pads and dials (set up for the Akai MPK)", and "a ROLI Seaboard MPE instrument that plays and draws each note's slide, bend, and pressure" was built during class at Marlon's request ("I want to use it and play music but also visualize it") [1]. The run of show's exercise: "MIDI pad → cue and dial → parameter ... everyone can use on-screen pads", with "a USB MIDI controller and cables" in the morning check [2]. The record does not confirm which parts students used in class [1].

## How to

From the run of show: connect the controller by USB, open the MIDI page, press a pad and use Learn to map it; on-screen pads stand in for hardware [2].

## Why to

Cue buttons for live events and performances, kept apart in the rotation from camera-based input "to isolate the different things students are learning to do" [1].

## Home game version

### In a regular classroom

On-screen pads or keyboard keys replace the hardware [2].

### Digitally

The same on-screen pads [2].
