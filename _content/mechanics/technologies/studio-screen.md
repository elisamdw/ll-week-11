# The studio screen

## Definition

The large display in a room that everyone can read at the same time (a projector on a screen or wall, or a big TV), used as the session's shared readout: what the whole room should see at once, as opposed to what each person sees on their own device.

## Description

From the record:

- **A reveal for a guessing game.** Nov 16, 05:58 (voice agent's record): fifteen terms in a category, displayed "one by one, slowly ... on the screen in the studio, and people have to try to guess the category" [1]; the card proposes a full-screen page with "huge type, one term at a time on a timer" [2].
- **A game show board.** EXPOS 40's *Are You Serious?!*: the fellows could "Play the board on the studio screen" [3].
- **A stage for live events.** TDM 155AI, Nov 11, 2026, planned: "a stage window on the projector, audio through the PA" [4]; the class app was built so that "every mechanic fires a cue or sets a parameter on a full-screen `/stage` window for the projector", but which parts ran in class is not confirmed [5].
- **A projected map to annotate.** NEC 101, spring 2025: "projecting dynamic visuals across a 30-foot blackboard wall" while students annotate with chalk and post-its [6].
- **A live feed.** In the nonverbal workshop plan, the classroom TV shows the overhead camera, then a laptop: "output 5 ... is what the classroom tv gets" [7]. TDM 119B, spring 2025, opened "by projecting live spectrograms of students' voices" [6].

## How to

1. **Full screen, large type,** made for reading across a room [2].
2. **Route it:** a laptop window on the projector [4], or a switcher output to the TV [7].
3. **Keep the host's controls off the shared screen:** the guessing game's host uses a key to stop the reveal and enters scores [2]; the stage window is driven from a separate launcher [5].

## Why to

From the record: everyone sees the same thing at the same moment, which a reveal, a countdown or a live performance needs [1][4]; and the large projection turns a map or timeline into something a whole class can work on at once [6].

**Proposed, for Marlon to choose:** how the entry pairs the shared screen with the private one.

1. Shared screen for public state, phones for private state: the rule for every LL game this week.
2. Shared screen as the "table" for remote players, so a home game can be played in a room with only a projector.

## Home game version

### In a regular classroom

The room's projector shows the same full-screen page from the instructor's laptop; nothing else is needed [2][3].

### Digitally

Screen-share the same page in a video call; a reveal still works when everyone sees one shared screen.
