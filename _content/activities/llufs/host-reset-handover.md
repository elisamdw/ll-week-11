# Host it, reset it, hand it over

1. **Pack the station (5 min).** Choose one tested mechanic. Put its route, host address if needed, materials, starting state, controls and reset on one sheet. Add the keyboard or paper fallback.
2. **Invite a new player (5 min).** Give a one-sentence invitation and let the player try. Observer records where the invitation or feedback fails. The host should explain the activity, not operate every move for the player.
3. **Practice recovery (5 min).** Reload the page, close a phone tab or remove an optional sensor. Reset with the instructions and compare the resulting state with the sheet. Stop if the reset changes another group’s active room; use an agreed separate room or paper copy.
4. **Hand over (5 min).** A different pair hosts from the sheet without coaching. Write ready, needs repair or untested next to each path. A laptop test does not establish phone or NFC readiness.
5. **Return evidence to the lead (5 min).** Give AL and the selected prototype’s builder the route/version, tested devices, remaining faults and proposed station role. Staff confirms whether it belongs in class and who can run it; this card assigns no fellow’s shift.

**What it teaches:** a mechanic becomes a usable studio experience through clear feedback, repeatable setup and a host who can let players act. Schell’s broader design frame treats the invitation and presentation as design work alongside mechanics and technology.

**Prepare:** confirm the Wednesday class plan with TD/AL; check the station does not conflict with booked studio use. Print from an LL computer under the standing fellows’ protocol. Keep this week’s bounded hosting task separate from Marlon’s next-term electronics-owner idea.

**Try it:** a single table, one laptop, the station’s paper pieces and a one-page instruction sheet; another pair must be able to reach and reset its starting state.

**What could go wrong:** hidden setup knowledge, stale QR links or a sensor that only its builder can repair. Remove that dependency or label the station needs repair; do not report rehearsal as a class outcome.
