# A station with two ways in

**LU’s proposal:** a fellow pair owns a small experience for a shift: a printed board, a playable mechanic, a short invitation and a reset. The host should be able to hand it to another pair without a developer explaining it.

The physical path could be a gesture, camera or NFC token, after the available kit is checked. The second path is a key, a click or a human scorekeeper. Both should mean the same move; a fallback that changes the game cannot tell us whether the physical interface helped.

**What fellows do:** choose one PL prototype, write “You can ___; this changes ___,” make three paper tokens, and compare two ways of taking that action. Ask a fresh player to tell the next host how it works. Keep an observation, a design suggestion and a technical fault as separate entries.

**Why:** Schell’s tetrad gives permission to change the invitation, story and presentation as well as mechanics. Sicart supplies the question about which action changes which state. This is a bounded week 11 station, not the next-term electronics ownership Marlon proposed.

**Prepare:** staff confirms shifts, the class station choice and a safe place for the laptop and kit. Builder checks the selected prototype’s current card before promising a feature.

**Try it:** one table, a laptop, three tokens and a printed keyboard legend. The station must remain playable when the optional sensor is unplugged.

**What could go wrong:** an impressive input hides an unclear game; a host silently repairs every mistake. Run the handover without coaching before calling it ready.
