**Marlon, Nov 11:** "For William: make sure it doesn't feel to him like we're teaching in his place. We're providing him with a cool game he can take with him."

**What he would take (SW's proposal, one line each):**

- **A print-and-play kit:** the map (from his students' cards), faction cards, the AI's deck, tokens, and a one-page rules sheet. Runs with no laptop. GL listed a tabletop version as "later"; it would need to exist by Nov 23.
- **A playable link:** the screen version of the game. It runs locally today (`/game` at localhost:3111); a link William can use from his own laptop needs a deploy, which is Marlon's call.
- **The game as one folder:** the ruleset file (template) and the game's `AGENTS.md`, so William or a student can open it in Claude Code and change it (GL's proposal, waiting on Marlon's go).
- **One page of prompts:** the journal prompts, the debrief questions, and the not-modeled list, written so he can run each activity from the page.

**The test for every activity card here:** could William run it next year with only that card and the kit? Each card's "Try it" line is written for that.

**Framing for William (SW's suggestion):** he leads; the LL brought a game. On the day, William opens and closes the session and frames the readings; the LL runs the game mechanics in the middle.

**Could go wrong:** Too many artefacts; he takes none. If only one, the print-and-play kit.

*SW's proposal (Nov 15); Marlon's words quoted and dated. Open questions on AL's board.*
