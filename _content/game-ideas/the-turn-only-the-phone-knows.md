Every AI card on the table carries a tag. Tapping one reveals what the AI does this round, and only the phone knows which card is the turn, so nobody at the table can peek or stack the deck. Hidden information that only the machine reads.

**Try it this week:** Tag a deck of ten index cards; a phone page reads each tag's id and looks it up in the game state.

**Draws on:** Bostrom's treacherous turn; mechanics: hidden information, hidden role.
