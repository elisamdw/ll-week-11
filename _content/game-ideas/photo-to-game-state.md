Marlon (voice chat): "go from a board game to how you would represent the data of that board game as a game state." The overhead camera takes a photo; Claude turns it into the state (who holds what, the values on the board); the class checks it against the table. What the photo can't see (hands, intentions) is the lesson.

**Try it this week:** Monopoly at the start and after ten minutes; two photos, two state tables.
