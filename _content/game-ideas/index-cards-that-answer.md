The September 28 index cards become the board. Each card is a template (the place as the students defined it); tapping it shows the instance (who holds it now, what it produces, whether it's down). The physical card stays the same while its game state changes.

**Try it this week:** Sticker five copies of the cards; a phone page maps tag ids to places in the Data Center game.

**Draws on:** Template and instance (HI's game-state pages); Star on infrastructure.
