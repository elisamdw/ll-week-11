# Database as Symbolic Form

**Citation:** Manovich, Lev. "Database as Symbolic Form." *Convergence* 5, no. 2 (1999): 80–99. https://doi.org/10.1177/135485659900500206. Revised in Manovich, *The Language of New Media* (Cambridge, MA: MIT Press, 2001). (Journal pages from The Notebook's copy; the manovich.net PDF says the text is a section of the book "written in the Fall 1998," seen; the book's city from memory.)

**What it argues:** Where the novel and cinema made narrative the key cultural form of the modern age, the computer makes the database its correlate: "a list of items which it refuses to order," while narrative makes a cause-and-effect trajectory (p. 85, seen). Games are the exception that proves the pairing. In the section "Data and algorithm" he writes that "while computer games do not follow a database logic, they appear to be ruled by another logic - that of the algorithm," and that a player who stops following an algorithm is still "discovering the algorithm of the game itself," as Will Wright puts it, building "a mental model of the computer model" (p. 83, seen). Data structures and algorithms are "two halves of the ontology of the world according to a computer" (p. 84, seen), and in new media the database (the paradigm) is made material while the narrative (the syntagm) becomes one path through it.

**Why it's canonical:** It names the database as a cultural form for new media studies, has three later book reprints listed on OpenAlex, and the book chapter it became is taught in data and media courses (Davidson 2014). Stafford assigns it this term in the database week, so Marlon's class and Stafford's share it.

**Key terms:** database vs. narrative, symbolic form, data structures and algorithms, the player discovering the algorithm, paradigm and syntagm, the interface to a database, database cinema.

**For the game (TH proposal):** (B, debrief) Database and algorithm, separated: after students photograph a board game from overhead and write its state as data, they name the algorithm a player has to uncover to win; then the same for Data Center, where `data-center.json` holds the database (nodes, resources, the deck) and the AI's upkeep, acceleration, and spread are the algorithm the humans reconstruct by playing, so one Claude Code remix changes only the data and another only the algorithm, and the debrief asks which one changed the game's argument.
