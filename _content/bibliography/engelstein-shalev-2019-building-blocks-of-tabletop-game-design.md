# Building Blocks of Tabletop Game Design

**Citation:** Engelstein, Geoffrey, and Isaac Shalev. *Building Blocks of Tabletop Game Design: An Encyclopedia of Mechanisms*. Boca Raton, FL: CRC Press, 2019. 2nd ed., 2022; 3rd ed., 2026. (Place from the publisher's usual imprint, unverified.)

**What it argues:** Less an argument than a reference: hundreds of board-game mechanisms, each a two-to-three-page entry with a code (STR-07 Traitor Games, ACT-14 Advantage Token), a diagram, a description, a discussion of how and when to use it, and sample games with designer and year (Meeple Mountain review, seen). The thirteen chapters are Game Structure, Turn Order and Structure, Actions, Resolution, Game End and Victory, Uncertainty, Economics, Auctions, Worker Placement, Movement, Area Control, Set Collection, and Card Mechanisms (Routledge, seen); reviewers name entries such as semi-cooperative and traitor games, single-loser games, player elimination, fixed and claimed turn order, and deck-building (seen). The summary comes from the publisher pages and two reviews; the book's text was not opened.

**Why it's canonical:** It is the field's dictionary of mechanisms, in its third edition and on Wesleyan's game lab reading list (2024). It is canonical for designers rather than for game studies: scholars cite it modestly (about 130 works across two OpenAlex records), and it makes no claim about what games mean.

**Key terms:** mechanism as a named, coded unit; game structure (competitive, cooperative, semi-cooperative, traitor); turn order; action selection; resolution; game end and victory; worker placement; area control; card mechanisms.

**For the game (TH proposal):** (editor) each rule in `/game/edit` carries the code of its nearest Building Blocks mechanism beside its `rhetoric` line, so students can look up how designers use it and swap one mechanism for another; Data Center itself is a semi-cooperative game with a traitor card (the AI's turn), STR-07 played by the deck instead of a person.
