# Cybertext: Perspectives on Ergodic Literature

**Citation:** Aarseth, Espen J. *Cybertext: Perspectives on Ergodic Literature*. Baltimore: Johns Hopkins University Press, 1997.

**What it argues:** Some texts make the reader work to get through them: adventure games, MUDs, hypertexts, the *I Ching*, a printed Dungeons & Dragons module. Aarseth calls these **ergodic** (Greek *ergon*, work, and *hodos*, path): "In ergodic literature, nontrivial effort is required to allow the reader to traverse the text" (quoted in Malloy's Leonardo review, seen; the book's pp. 1–2, unverified). He treats a **cybertext** as a machine for producing expression and builds a typology of such machines by how the user acts on them, rather than treating games as stories told in a new medium.

**Why it's canonical:** It is the book that let game studies start from games as machines instead of as narratives; Frasca's ludology essay names Aarseth as the main challenger of the narrative paradigm, and its introduction is the standard first reading for "games as cybertexts" (MIT CMS.300). Aarseth's companion essay "Genre Trouble" is in *First Person* (2004).

**Key terms:** ergodic literature, cybertext, textons and scriptons, traversal function, user functions (interpretive, explorative, configurative, textonic), textual machine.

**For the game (TH proposal):** the editor is Aarseth's **configurative** user function made literal: once per game, a faction may rewrite one AI rule in `/game/edit`, and the AI's next deck is generated from the changed table (editor, B).
