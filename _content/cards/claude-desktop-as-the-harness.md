> a new workspace for exploring this repo and things like it = learning-with-ai tools: https://github.com/amosblomqvist/learnharness def want to help students and faculty think about building things like this, but initially within claude desktop . . . like having persistent graphs and data in your claude desktop project can reproduce elements of this sort of thing.

> then helps me set students in my class up to create a simple web based learning game/environment, but also to use Claude Desktop (code) as the harness for this....

Marlon, Nov 15, just before 08:18, starting the learning-harness workspace (`W11/days/20261115/README.md`).

The proposal inside it: much of what a learning app does can be had without building the app. A Claude Desktop project, or a folder Claude Code reads and writes, can hold the persistent parts (a graph of ideas, a record of each session) and Claude does the rest. The web game is a second, optional layer that reads the same files.

The learning-harness workspace is building this now, in `_content/learning/` (a starter folder, a Desktop trial, a `/learn` web game). One limit it found, from Anthropic's quickstart: the Desktop Code tab needs a paid plan, and what students' Harvard accounts give them is a question waiting on Marlon.
