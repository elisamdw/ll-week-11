> a game generation tool potentially.

Marlon, Nov 13, dictated, closing the sentence about the mechanics inventory and "a gamified way of interacting with them" (`W11/marlon/20261113-games-and-interaction.md`).

"Potentially" makes it a seed. Read beside the Nov 14 decisions, as CI reads them, the tool may already exist: Claude Code with a repo that holds the inventory and a working game can generate a game from three mechanics when asked ("The UI is Claude code itself"). What a dedicated tool would add is the constraint: a fixed set of mechanics to draw from, a template to fill, a result that plays at once. The builds list records it as a proposal, not started.
