**What it is.** Twenty-five minutes in William's workshop, and the same activity as Wednesday's [Remix a mechanic with Claude Code](remix-a-mechanic-with-claude-code.md) with a different rule about AI. William's syllabus keeps submitted work free of AI help, so here Claude Code is something the class watches and examines, not a tool for the students' own writing.

**How it plays.** Each table picks one change from a printed menu, or invents one. SW's menu ties each to a reading or a prototype: prices that rise as the AI buys ([Prices that move](prices-that-move.md)); every resource drawn from a named place (Crawford; [Every resource names a place](every-resource-names-a-place.md)); a workers' faction that can strike (Rabinbach; [A logistics and labor faction](a-logistics-and-labor-faction.md)); goals rewritten when the AI builds nearby (Winner); an advisor on the council that is right most of the time ([The committee](the-committee.md)); the AI's next target shown to one player ([The readout](the-readout.md)); a compute cap everyone must vote to raise; fast or slow AI by vote before play; a rival lab with a treaty as the only brake ([The race](the-race.md)). At one table an LL facilitator types the table's plain-words request into Claude Code, which puts the change in a new remix folder; the other table writes its change as a house rule on a card. They swap at 14:12 if both are ready. Two rounds with the change, then one sentence: what does the game argue now that it didn't before? That sentence is the students' own.

**What it does for learning.** Changing one mechanic and watching the outcome move is the clearest way to see a game as an argument (SW, after Bogost, Sicart and Schell's elements). The two routes, screen and paper, also let the room see what Claude Code adds and what it doesn't.

**Which of Marlon's ideas it serves.**

> The key thing is that the students need agency, and I'm not sure that playing an existing game we create is enough

Marlon, Nov 14, on the options for the Stafford game, recorded in `_content/game/design.md`.

> I don't need to build a UI for that designing or remixing. The UI is Claude code itself.

Marlon, Nov 14, in a voice chat with Claude, as transcribed in the handoff back to Claude Code (section 2). CI's card [Claude Code is the UI](claude-code-is-the-ui.md) holds the idea.
