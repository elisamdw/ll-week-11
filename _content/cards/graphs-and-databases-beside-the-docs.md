> Addition: but we want to get one step past this by having some graph and database-like structures, in addition to the markdown docs.

Voice Claude's summary of Marlon's words, Nov 15, about 11:07, in the thread "Idea: harness and agent engineering," #mk-work-in-progress.

"In addition to," not "instead of": the documents stay the truth, and the structures sit beside them. These cards are a small example. Each is a document, and its frontmatter (`follows`, `links`, `convolute`) is a graph that a view can draw. The same pattern appears in the learning harness (a graph of ideas in JSON next to session notes) and in a game (a save file next to the rules).

What it raises, CI's question: when the document and the structure disagree, which wins? Keeping the structure inside the document, as frontmatter does, is one answer.
