**What it is.** HB's seventy-five-minute session, turned by Marlon's choice into the take-home over Thanksgiving. The idea in HB's line: the folder is the tutor and its memory; the web page is a game made from that memory. This card starts a `follows` chain.

**How it runs.** Setup first (Claude Desktop, the Code tab, the harness folder from `starters/learning-harness/`, edits accepted), then [Learn something in the folder](learn-in-the-folder.md), then [Make a game from your graph](make-a-game-from-your-graph.md); the pair steps work solo. In class, the plan ends with two or three students on the projector: their map, a remix in one line, and one question it raised. As a take-home, that becomes a short showing on December 2. HB's prompts for the room: what does the game reward that the tutor didn't? What does the map make visible that the conversation hid?

**What it does for learning.** It ties the harness to the week's other cards. The learner's graph is a game state (TD's *A game is data*); remixing the game is the same move as [Remix a mechanic with Claude Code](remix-a-mechanic-with-claude-code.md), on a game the student made from their own learning; and a learning game argues something about learning (that it unlocks, that it is a path, that missing costs), which is *Agency or argument* again.
