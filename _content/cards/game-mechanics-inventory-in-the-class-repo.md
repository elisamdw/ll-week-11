An inventory is a list of a field's verbs, and the first thing a class repo holds, as CI reads it: before students design a game they need words for its parts. The class repo got 50 cards on Nov 13 (one file each, an index, an 11x17 poster print); by Nov 14, HI had grown it to 105 rows in `_content/mechanics/mechanics.csv` in this repo, each with an example, a thing to try, a way to build it, and its readings, shaped for Airtable.

Which Airtable base it goes into was still Marlon's call at the end of Nov 14, and no writes were made. Two copies now exist (the class repo's 50, this repo's 105), and which is the source is a question for him.
