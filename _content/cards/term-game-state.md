The game state is everything that is true about a game at one moment: positions, scores, whose turn it is, what is hidden. A board game keeps it on the table; a video game keeps it as data. Much of this week turns on it: photograph a board, write its state down, save it, load it again.

---

**Where the term comes from.** Sicart defines mechanics as interaction "with the game state" (2008). Greg Costikyan, on Monopoly: "You choose whether or not to buy a property you land on; the game state changes in response to your decision" (2002, p. 11). Juul: a board game keeps its state in "cards and board pieces"; a computer has "the memory capacity to remember game state" (2003).

**This week.** A photograph of a Monopoly game in progress shows most of its state (tokens, houses, cash) but not the order of the Chance deck or anyone's plans. HI's game-state pages model Monopoly, Risk, Life, Hold'em, Civilization, *Universal Paperclips* and the AI game as data.
