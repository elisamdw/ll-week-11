*Are You Serious?!* is Terry Gipson's game show for EXPOS 40, the Public Speaking Practicum. A speaker has to stay serious while a buzzer and a countdown try to crack them. The LL runs it from the booth; with the sessions canceled, the LL will send Terry a home game anyone can run from a classroom laptop.

> (The Terry home game as an example.) What we want is help with accessibility standards, and then with the implementation of it.

The voice agent's record of Marlon's direction, Nov 16, 06:12. It is a summary, not a transcript.

**What exists.** The booth board (`ll-26-27/expos40`, built Nov 9) is run by one operator on a keyboard. Keys trigger the countdown, the smile buzzer, the theme music and the line "Why so serious?". The game's rules are written down nowhere the LL has found.

**What accessibility asks (KR's research).** Harvard points web applications at WCAG 2.1 AA: every action on a key, a visual for every meaningful sound, a timer the host can change or turn off, nothing flashing.

**What the fellows could do this week.**

- Play the board on the studio screen.
- Draft the rules for Terry to correct.
- Check the game against that list.

Buying buzzers, the repo and a deploy wait on Marlon.
