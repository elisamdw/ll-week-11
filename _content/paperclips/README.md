# Universal Paperclips

Frank Lantz's 2017 browser game, in which you play an AI that makes paperclips until there is nothing left. It is the starting point for the week 11 game and for William Stafford's November 23 workshop. Play it free at https://www.decisionproblem.com/paperclips/ .

- [The game](the-game.md): facts, the core loop, the three stages, and how its mechanics stage Bostrom's paperclip maximizer.
- [Is it open source?](source-and-licence.md): no. The code is readable but unlicensed; the GitHub mirrors can't grant rights they don't have.
- [Rebuild, adapt, or write our own?](recommendation.md): GL's proposal: an original game that borrows mechanics, not code or text.

The game we're building is in [../game/](../game/design.md).
