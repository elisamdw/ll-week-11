## Overview: four relationships, one machine

Games and AI have grown up together, and their history is four relationships braided into one.

**Games test AI.** From the start, AI researchers picked games as their fruit fly: bounded, cheap, and scored. Turing wrote a chess program before there was a computer to run it (1948) and played it by hand; Shannon's 1950 paper set the method that Deep Blue would finish in 1997. Arthur Samuel's checkers program taught itself by playing itself, and in 1959 he gave the practice its name, machine learning. Each era's idea of intelligence can be read off the game it chose: search and calculation (chess), learning from experience (checkers, backgammon), perception (Atari), intuition (Go), deception and hidden information (poker), teamwork and real time (*Dota*, *StarCraft*), negotiation in language (*Diplomacy*), and now persistence over days (Pokémon). John McCarthy's 1997 complaint shadows the whole story: a win can stand in for understanding while hiding how little carries over.

**Games contain AI.** For game designers, "AI" has meant something different: not a mind but an illusion of one, built to make play interesting. The four ghosts of *Pac-Man* (1980) have four simple rules that read as four personalities. Strategy games gave players rivals who scheme, and who also cheat. *The Sims* put the intelligence in the objects; *F.E.A.R.* gave soldiers a planner; *Façade* tried to let players speak; *Left 4 Dead*'s Director paced fear like a film editor; *Shadow of Mordor*'s Nemesis system made enemies remember you. Then language models turned NPCs from scripted to improvised, and world models began to generate the game itself, frame by frame. The question shifted from "is the AI smart?" to "is it fun, fair, and on script?"

**Games imagine AI.** Games about AI keep putting the machine in the player's interface or the player in the machine. SHODAN and GLaDOS give the orders; Elohim forbids the tower; Friend Computer accuses you of treason; the *Eliza* app writes what its human proxy must say; *Universal Paperclips* makes you the optimizer. Because a game is itself a system of rules the player negotiates with, it can stage obedience, runaway goals, and machine personhood in a way films only depict.

**AI makes games.** Procedural generation has been a production technique since *Rogue* and *Elite*: rules instead of memory. Machine learning came in quietly through animation, upscaling, cheat detection and testing, then loudly through generative tools for art, code and voice. The loud part became a labor fight: the SAG-AFTRA video-game strike (2024–25) won consent and disclosure for digital replicas; studios split between "AI first" (Krafton) and "no AI-generated assets" (Capcom); this very week, IGF jurors and *Big Walk*'s developers argued over whether a code assistant counts.

**And learning runs through all four.** PLATO, built to teach, became a game platform; the ESP Game, *Quick, Draw!* and *Foldit* turned play into training data; Duolingo joined gamification to an adaptive model and then to an LLM tutor.

**Why it matters for this week.** The game GL is building, *Data Center*, sits where the four meet: an AI system on a shared map (AI inside a game), about an AI consuming infrastructure (a game about AI), drawn from a long tradition of games as tests (proving ground), built partly with AI tools in a week when what that means is contested (AI in game development). Each strand ends with proposals for how it could feed the game's rulesets and Marlon's classes.
