# Cognitive tutors and knowledge tracing

**What and when — source account.** Cognitive tutors model component procedures. Corbett and Anderson’s Knowledge Tracing paper describes the ACT Programming Tutor choosing practice from estimates of rule learning.

**Learner model — HR’s reading.** Model tracing checks a learner’s problem-solving steps against a cognitive model; knowledge tracing estimates whether component skills have been learned.

**Game-like, or not — HR’s reading.** Hints, local feedback and progression can structure a challenge without fantasy or competition.

**What we can borrow — proposal.** Record the evidence behind each skill estimate. A correct response can involve a guess; an error can be a slip.

**Evidence and media notes.** 1995 follows the imprint and received/revised dates visible in the indexed primary PDF; the paper is also widely indexed as 1994. It is a publication marker, not the first cognitive tutor. No verified media embed.
