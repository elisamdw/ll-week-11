# Khan Academy’s mastery system

**What and when — source account.** The Course and Unit Mastery system tracks skills within courses. A September 2018 official update documents changes to that system; Khan Academy itself is older.

**Learner model — HR’s reading.** A skill can move through Not started, Attempted, Familiar, Proficient and Mastered. Assessments can change its recorded level.

**Game-like, or not — HR’s reading.** Leveling and visible progress organize practice. A percentage summarizes the platform’s skill model.

**What we can borrow — proposal.** Show progress at the skill level and make reassessment possible; do not treat a course percentage as a complete description of learning.

**Evidence and media notes.** Official help read 2026-11-15. Year is a documented system revision. No verified media embed.
