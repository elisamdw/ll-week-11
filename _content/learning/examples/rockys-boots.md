# Rocky’s Boots

**What and when — source account.** An early educational game about constructing working logic machines. Its archival manual credits Robinett as author; gates, sensors and a kicking boot turn Boolean logic into something that acts.

**Learner model — HR’s reading.** The constructed circuit and its output show what the player understands; do not assume this is a probabilistic learner model.

**Game-like, or not — HR’s reading.** Spatial exploration and a machine that must select the right objects integrate the learning task with play.

**What we can borrow — proposal.** Make the learner build a mechanism whose success demonstrates the target idea.

**Evidence and media notes.** The Computer History Museum-hosted survey explicitly credits Warren Robinett and Leslie Grimm, 1982, and illustrates the circuit puzzles.
