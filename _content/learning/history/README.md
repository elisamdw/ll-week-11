# Learning machines, worlds and tutors over time

A research collection for the November 15 learning-harness workspace. These examples overlap: AI tutoring existed decades before large language models, and some of the most expressive learning environments do not model the learner at all. This is a comparison of designs, not a story of inevitable progress.

Every card separates the source account, HR’s interpretation and a proposed borrowing. Official product descriptions were read on **November 15, 2026**; they establish what a developer describes, not independent proof that the product improves learning. Historical dates mark an artifact, publication, project period or release as specified on each card. Provisional dates are identified there.

## Four useful comparisons

- **The machine selects a next step:** [Pressey](../examples/pressey.md), [programmed instruction](../examples/programmed-instruction.md), [cognitive tutors](../examples/cognitive-tutors.md), [ALEKS](../examples/aleks.md), [Khan mastery](../examples/khan-mastery.md). Compare the evidence each can use.
- **The learner makes or explores a world:** [Logo](../examples/logo.md), [Mindstorms](../examples/mindstorms-microworlds.md), [Rocky’s Boots](../examples/rockys-boots.md), [Zoombinis](../examples/zoombinis.md). Compare freedom to make something with a prescribed learning path.
- **An agent participates in a game or learning role:** [Betty’s Brain](../examples/bettys-brain.md), [Crystal Island](../examples/crystal-island.md), [Operation ARIES!](../examples/operation-aries.md). These precede the current LLM era. [Quick, Draw!](../examples/quick-draw.md) and [AI for Oceans](../examples/ai-for-oceans.md) also make AI itself available for inspection.
- **A conversation acquires a durable record:** compare [ChatGPT study mode](../examples/chatgpt-study.md), [Claude Learning mode](../examples/claude-learning.md), [Gemini Guided Learning](../examples/gemini-guided.md) and [NotebookLM](../examples/notebooklm.md) with the three separately identified [Blomqvist](../examples/learnharness-blomqvist.md), [Yadav](../examples/learning-harness-yadav.md) and [h4ksclaw](../examples/learnharness-h4ksclaw.md) harnesses. Ask what survives the conversation, and what that record can justify.

## For the week’s build — HR’s proposals

Keep a subject graph, learner attempts, inferred progress and the game’s world state distinguishable. A source-grounded answer, a correctly recalled fact, a convincing explanation and a working construction supply different evidence. Let the student inspect and revise the harness’s interpretation.

This collection is a draft for Marlon’s review; it changes neither the agreed TDM class plan nor the class repository. No example app was installed or run, and no paid model calls were made.
